# Админка бота

Админка — это не веб-панель, а меню прямо в Telegram-чате с ботом: команда `/admin` строит клавиатуру снизу экрана (reply-keyboard) с кнопками, которые зависят от прав конкретного человека.

## Роли

### Супер-админ

Один аккаунт, задаётся **через `.env`** — переменная `SUPER_ADMIN_TELEGRAM_USER_ID` (числовой Telegram ID, не username). Как узнать свой числовой ID — написать боту [@userinfobot](https://t.me/userinfobot) или любому похожему.

Супер-админ:
- имеет **все права** автоматически, без строки в базе данных;
- единственный, кто может добавлять/удалять сотрудников (это не делегируется никому);
- не может быть добавлен/удалён через бота — только правкой `.env` и перезапуском.

### Сотрудники

Добавляются супер-админом через меню (раздел "👥 Сотрудники"). У каждого — свой набор прав из фиксированного списка:

| Право (ключ) | Что даёт |
|---|---|
| `manage_channels` | Добавлять/удалять Telegram-каналы, которые бот парсит на вакансии |
| `block_users` | Блокировать/разблокировать подписчиков бота |
| `manage_ads` | Управлять рекламными кампаниями (`/newad`, `/ads` и т.п.) |

Хранятся в таблице `staff_members` (`telegram_user_id`, JSON-список прав, кто добавил, статус). Удаление — мягкое (`status="removed"`): история не теряется, а если того же человека добавят снова — права просто обновятся.

## Команда `/admin`

Написать боту `/admin`. Если прав нет вообще — бот ответит "У тебя нет прав администратора." Если есть хотя бы одно право — появится клавиатура с кнопками только для того, что доступно:

- **📡 Каналы** — видна при `manage_channels`
- **🚫 Пользователи** — видна при `block_users`
- **📢 Реклама** — видна при `manage_ads`
- **👥 Сотрудники** — видна **только** супер-админу

## 📡 Каналы

**Виден только если в `.env` заполнены `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.** Без них Telegram-парсинг целиком отключён (hh.ru/LinkedIn это не затрагивает) — кнопка не показывается, даже если у человека есть право `manage_channels`.

Показывает список текущих каналов (🟢 активен / ⚪️ отключён) и кнопки:
- **➕ Добавить** — бот спросит юзернейм канала или ссылку (`@channel`, `https://t.me/channel`, `t.me/channel` или просто `channel` — любой формат распознаётся); следующее сообщение — ответ, канал сразу добавляется в список опроса.
- **🗑 <имя канала>** — отключает канал (мягко, не удаляет историю курсора — если добавить обратно, продолжит с того же места).

Канал должен быть **публичным** — Telethon-аккаунт должен иметь возможность читать его без приглашения.

## 🚫 Пользователи

Кнопки **🚫 Заблокировать** / **✅ Разблокировать** — бот спросит Telegram ID подписчика (число, не username). Заблокированный подписчик перестаёт получать рассылку вакансий и рекламы (статус `blocked` в таблице `subscribers`), но не теряет свои настройки — разблокировка возвращает всё как было.

## 📢 Реклама

Это не диалог, а просто подсказка с командами (управление кампаниями осталось на слэш-командах, не переведено в меню):

```
/newad Название | Текст объявления   — создать кампанию (черновик)
/ads                                  — список всех кампаний
/activatead <id>                      — запустить рассылку кампании
/canceladc <id>                       — отменить кампанию
/broadcastad <id>                     — разослать прямо сейчас, не дожидаясь расписания
```

Доступны и супер-админу, и любому сотруднику с правом `manage_ads`.

## 👥 Сотрудники (только супер-админ)

Список сотрудников (ID, username, права, статус) и кнопки:
- **➕ Добавить сотрудника** — бот спросит Telegram ID → затем покажет чеклист прав (✅/⬜ на каждое из трёх, тот же стиль, что в «➕ Добавить стек» у обычных подписчиков) → нажать "Готово" — сотрудник сохранён с выбранными правами.
- **🗑 <ID сотрудника>** — удаляет сразу, без подтверждения (мягко, можно добавить обратно).

## Технические детали (на будущее, если будешь что-то менять)

- Меню реализовано через `aiogram`'s FSM (`aiogram.fsm`) с дефолтным `MemoryStorage` — состояния диалогов живут в памяти процесса, **не переживают перезапуск бота**. Если бот перезапустится посреди диалога "добавь канал" — придётся начать заново (не страшно, просто имей в виду).
- Весь код — `src/jobsbot/bot/handlers/admin_menu.py` (меню, FSM) и `src/jobsbot/bot/permissions.py` (кто что может).
- Проверка прав продублирована на двух уровнях: кнопка не показывается, если права нет, но хендлер **всегда** перепроверяет право заново при нажатии — так что даже с "протухшей" или скопированной у другого чата клавиатурой ничего лишнего не выполнится.
